# Vendored Baker--Norine Riemann--Roch proof

The Lean sources in this directory are adapted from
[`DhyeyMavani2003/chip-firing-with-lean`](https://github.com/DhyeyMavani2003/chip-firing-with-lean/tree/v1.1.1),
co-developed by Dhyey Dharmendrakumar Mavani and Nathan Pflueger and released
under the Apache License 2.0.

Upstream version: `1.1.1`, originally targeting Lean/mathlib `v4.34.0-rc2`.
The copies here have been modified to use this project's module paths and to
compile with Lean/mathlib `v4.31.0`.  Only the dependency closure of the
Riemann--Roch theorem is included.

The full Apache 2.0 license is reproduced in `LICENSE`.
